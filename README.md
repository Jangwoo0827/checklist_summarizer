# 체크리스트 노트 (Checklist Note)

숙제나 할 일 목록을 텍스트로 붙여넣거나 사진으로 찍어서 바로 체크리스트로 만들어주는 단일 HTML 파일 웹 앱입니다. 빌드 도구나 서버 없이 브라우저에서 `checklist-note.html`을 열기만 하면 동작합니다.

## 기능

- 텍스트를 붙여넣으면 "1." "1)" 같은 번호나 Tab/스페이스 들여쓰기를 자동으로 인식해서 계층 구조 체크리스트를 만듭니다.
- 사진을 올리면 로컬에서 실행 중인 [Ollama](https://ollama.com)의 비전 모델로 목록을 인식합니다 (API 키 불필요, 사진이 인터넷으로 나가지 않음).
- 체크 상태와 여러 체크리스트는 브라우저 `localStorage`에 자동 저장됩니다.
- 상위 항목을 체크하면 하위 항목이 모두 체크되고, 반대도 동일하게 동작합니다.

## 사용법

1. `checklist-note.html`을 브라우저에서 엽니다.
2. 사진 인식을 쓰려면 [Ollama](https://ollama.com)를 설치하고 비전 모델을 받습니다:
   ```
   ollama pull minicpm-v
   ```
3. 로컬 파일(`file://`)에서 Ollama API로 접속하려면 CORS를 열어줘야 합니다 — 환경 변수 `OLLAMA_ORIGINS=*`를 설정한 뒤 Ollama를 실행하세요.
4. "+ 새 체크리스트 만들기"를 눌러 텍스트를 붙여넣거나 사진을 올립니다.

## 기술

순수 HTML/CSS/JavaScript(ES5)로 작성된 단일 파일이며, 외부 라이브러리나 빌드 과정이 없습니다.
